MAUI AppKit callback mixed-stack red/green

Fixture:
  C# MixedModeScenario.Run(19, 23)
    -> C++ native_callback_roundtrip
      -> C# ManagedCallback(42)
        -> native_checkpoint(3, 42)
      <- 84
    <- 126

Pre-production RED 1:
  The MAUI callback did not invoke a native checkpoint while its managed frame
  was active. `maui_debugger.py` timed out waiting for the LLDB stopped event.

Pre-production RED 2:
  After adding the callback checkpoint, LLDB stopped with native_checkpoint and
  native_callback_roundtrip on the stack, but no managed frames were published.
  The engine log reported:

    Managed inspection unavailable: ClrDebug.DebugException (0x80131C35):
    Error HRESULT CORDBG_E_MISSING_METADATA ...
    at DncDbg.Engine.CoreClrInspection.GetStackTrace

Root cause:
  A runtime/interop frame without managed metadata caused the entire stack walk
  to fail before reaching the user callback frame.

GREEN:
  CoreClrInspection skips an individual TryGetFrame result of
  CORDBG_E_MISSING_METADATA and continues the stack walk.

  python3 tests/DncDbg.MixedModeTests/maui_debugger.py

  PASS MAUI AppKit LLDB-owned mixed stack includes active C# callback

Assertions:
  - native_checkpoint is the top native frame.
  - native_callback_roundtrip remains on the physical native stack.
  - [Managed] MixedModeScenario.ManagedCallback is mapped into the hybrid stack.
  - managed callback source is MixedModeScenario.cs.
  - managed callback argument value is 42.
  - after continue, DevFlow observes MixedModeStatus.Text == 126.

Managed-address breakpoint RED:
  Reusing the managed frame's current safe-point InstructionPointerReference as
  either a standard setInstructionBreakpoints address or an LLDB hardware
  breakpoint did not stop the next callback invocation. The safe-point IP is not
  a stable method-entry breakpoint identity.

Managed-address breakpoint GREEN:
  ManagedInspectionFrame now preserves both:
    - InstructionPointer: current frame/safe-point PC used for native/managed
      frame correlation.
    - CodeStart: CorDebugNativeFrame.Code.Address used as the current native
      method entry.

  DNCDbg exposes CodeStart as dncdbgCodeStartReference on a managed hybrid frame.
  The proof installs:

    breakpoint set --hardware -a <dncdbgCodeStartReference>

  It clears the original native checkpoint breakpoint, continues, and invokes
  the same MAUI button again through the same DevFlow batch session. LLDB stops
  at the managed callback code start, DNCDbg maps the stop to
  [Managed] MixedModeScenario.ManagedCallback, and the final DevFlow assertion
  remains MixedModeStatus.Text == 126.

  python3 tests/DncDbg.MixedModeTests/maui_debugger.py

  PASS MAUI AppKit mixed stack and LLDB managed-address callback breakpoint
